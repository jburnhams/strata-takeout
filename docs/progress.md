# strata-takeout progress

## 2026-11-07: created
Moved here from `~/.local/bin` on a home Linux box, where it was written the same day while the first full Google Takeout (3.2 TiB, 789 files on Drive) was being pulled. The scripts are unchanged except that the tool paths (`SAFE_EXTRACT`, `FILECAT`) are now configurable. The Python parts (path rules, safe extractor, filecat profile) became a package with tests.

Decisions:
- Google first, as scripts; no premature plugin interface (see docs/platforms.md). Port the bash to Python only with tests, not during a live download.
- Standard library only. External tools: rclone (fetch), bsdtar (fast extraction), optionally filecat.
- Staging on the NVMe, archives kept in `done/` after extraction, loose non-archive files in `loose/`, `dupes.tsv` and `renamed.tsv` as the records of what was renamed.
- Everything that touches data is covered by the integration tests in `tests/integration/test_takeout_extract.py` (oldest-first, the download gate, nested skip, long names, twins, corrupt archive).

Open: `takeout-pull` tests (needs a fake rclone), a second platform, a request/reminder helper for tier-B services, own Google client id.

## 2026-11-11: second Google account (brand YouTube channel)
A Takeout of a second Google account (a brand YouTube channel: own uploads, My Activity, YouTube) was dropped in the inbox as its own platform, `google2`. Decision: it is its own inbox platform, `google2` -> `<exports>/google2/tree/` + its own filecat collection, never `google/` (that merges into `/srv/exports/gt` and would overwrite the main account's files at the same paths). Inbox change: platforms whose name starts with `google` extract with `Takeout/` stripped (`strip_for`), so both trees have the same layout (`YouTube and YouTube Music/...`, `My Activity/...`) and the same parsers work on either. Not routed through the Drive pipeline (no Drive for this account; the manual download is the fetch).

## 2026-11-11: YouTube history into the shared database
`strata-takeout-youtube` (`src/strata_takeout/youtube/`, install extra `[youtube]`): parses `watch-history.html`, `search-history.html` and `My Activity/YouTube/My Activity.html` of every configured Google tree into schema `youtube` of the shared database (tables `accounts`, `activity`, `sources`, view `watches`; models and Alembic migrations here, `[tool.omarchy-db]` in pyproject). Accounts are never defaulted: the job passes the `youtube_accounts` setting (strata-python Settings, env `STRATA_TAKEOUT_YOUTUBE_ACCOUNTS`, `id[:label]=tree,...`), so a new Google tree is one more entry; the account's own channel id is read from `channels/channel.csv`. Idempotent: `sources` records each file's size and mtime; an unchanged file is skipped, a changed one replaces all rows of its (account, source) in one transaction. Runs through `takeout-youtube.service`, started by `OnSuccess=` of `takeout-extract.service` and `takeout-inbox.service`. Takeout times are local with an abbreviation (BST/GMT), stored as UTC. `my-activity` repeats `watch-history` watches: count watches through the `watches` view.

### 2026-11-11 (later): all other YouTube files too
`youtube/datasets.py` loads the rest of the Takeout's `YouTube and YouTube Music/` CSVs, each whole and idempotent (fingerprint of its files in `sources`; a tree without the file never wipes rows): `subscriptions`, `playlists` + `playlist_items` (file name matched to the playlist title, `_` standing for characters a file name cannot hold), `videos` (own uploads: videos + `(1)`/`(2)` twins + recordings + texts; 0,0 location = none), `own_channels`, `comments` (text segments joined, raw JSON kept), `live_chats`, `messages` (no text in Takeout), `music_tracks` (library + upload metadata, 50k rows). YouTube Kids profiles (`children/<name>/watch-history.html`) load into `activity` as source `kids-<name>`, outside the `watches` view. Not loaded: the media files themselves (uploaded mp3s, the account's own videos: filecat's job), and `My Activity` for non-YouTube products. Loaded live: activity 103k, subscriptions 1,201, playlist items 409, own videos 479, comments 94, music 50k. No watch duration, recommendations or impressions exist in Takeout. ~205 brand and ~113 main My Activity watches have no twin in watch-history (see `watches` view note): `watches` stays watch-history only.
Known flake, not from this change: `tests/unit/test_nested.py::test_extract_writes_only_the_plan_keeps_file_and_folder_and_is_resumable` fails about 1 run in 4 (two worker threads).
