# Repository Guidelines

**This repo is going public: keep everything generic.** No personal details anywhere in code, tests, docs, comments, commit messages or PRs: no names, e-mail addresses, account or channel names or ids, hostnames, real export contents or numbers about someone's own data. Tests use synthetic fixtures only. **No machine paths either** (no `/srv/...`, no `~/...` folders of one person's setup): paths and account lists are passed in by the job that runs the tool (environment variable, setting or argument; the deployed units and their drop-ins live outside this repo), and new code must not default to them. Existing path defaults in the older scripts (`EXPORTS_ROOT`, `INBOX`, `nested --gt-root`, ...) are to be removed the same way; do not add new ones. Notes about a particular machine or account belong in the owner's own docs.

strata-takeout: download, extract and catalogue the data exports of online services (Google Takeout first; Meta, X, Amazon, Apple, Reddit, Flickr, ... planned, see `docs/platforms.md`). Pairs with [strata-filecat](https://github.com/jburnhams/strata-filecat) (catalogue, hash index, duplicate finder).

- Python (standard library only, except `src/strata_takeout/youtube/` which needs the `[youtube]` extra: omarchy-db, strata-python) in `src/strata_takeout/`: `paths.py` (what an archive entry name becomes on disk: leading `Takeout/` dropped, over-long names cut + hashed, nested `Drive/Takeout/` skipped), `safe_extract.py` (extractor that never fails on names; CLI `strata-takeout-safe-extract`), `profile.py` (the `takeout` filecat profile, entry point group `filecat.profiles`), `inbox.py` (CLI `strata-takeout-inbox`: ingests archives and files dropped into per-platform inbox folders), `platforms/` (per-platform Python code when needed).
- The inbox never deletes anything from the drop folder before the extraction succeeded, never touches a file that is still growing (mtime/ctime older than SETTLE and an unchanged size), and keeps the original archive. Keep it that way.
- Scripts: `scripts/google/takeout-pull` (rclone move from Drive; `--files` for non-archives, default for archives staged on fast disk in capped batches), `scripts/google/takeout-extract` (oldest export first, gated while downloading, bsdtar with fallback to the safe extractor, archives to `done/`, twins and nested rules, records in filecat), `scripts/setup-exports-disk` (LUKS2 + ext4 data disk, destructive: needs `DISK_SERIAL` and `DISK_MODEL`, asks you to type the serial), `scripts/install.sh`. systemd units in `systemd/`.
- Tests: `tests/unit` (paths, extractor, profile) and `tests/integration/test_takeout_extract.py` (runs the real bash script with fake exports; needs bsdtar). Hermetic: temporary directories, `SAFE_EXTRACT`/`FILECAT` overridden. Tooling is **uv**: `uv sync` builds `.venv` from the committed `uv.lock` (`uv add --group dev <pkg>` changes dependencies, commit `pyproject.toml` and `uv.lock` together). **Run `scripts/check` before every commit** (`--fast` skips the tests, `--fix` applies ruff): `uv run --locked strata-check` from [strata-python](https://github.com/jburnhams/strata-python) runs `uv lock --check`, `ruff check`, `ruff format --check`, `pyright` and `ty`, then the tests with coverage (they need `bsdtar`: `libarchive-tools`; CI installs it). Pyright is strict for the files under `strict` in `pyproject.toml` (a ratchet: never remove one); `pytest.importorskip` is banned. The app itself stays standard library only (strata-python is in the dev group for its gate). CI is `.github/workflows/unit.yml`, `upgrade-strata-python.yml` (weekly PR that moves the gate's pin after it passes) and `.github/dependabot.yml` (daily, no ignores).
- **Open problem (2026-11-08):** skipping `Drive/Takeout/` loses data: the nested zips are mostly NOT duplicated elsewhere (see docs/platforms.md CORRECTION). Never delete wrapper archives until nested extraction exists.
- Ordering rule that matters: archives of one platform are extracted **oldest export first** (so newer overwrites older); while a download is running only exports <= the oldest partial are extracted. Same-export files that were renamed apart (`dupes.tsv`) wait for all twins and go by modification time. Do not break these without a test.
- Editing a script that a systemd unit may be running: replace the file (write a temp file, then `mv`), never rewrite it in place: bash reads scripts incrementally.
- Deleting from the remote is permanent and happens only after rclone verified the local copy. Never add a code path that deletes remote data before that.
- Style: dense, comment-the-why, `ruff format` at line length 120 (do not hand-format). No secrets in the repo; rclone config and account logins live outside it.
- Notes and decisions: `docs/progress.md`. Notes about a particular machine's setup are kept outside this repo.
- `strata-takeout-youtube sync` (src/strata_takeout/youtube/, schema `youtube`, `systemd/takeout-youtube.service` started via `OnSuccess=` of the extract and inbox units; the accounts come from the job's environment, never a default): parsers and ingest are idempotent (file size/mtime in `sources`, replace per (account, source)); change a model → `dbtool revision -m "..."`, `dbtool check`; run the suite with `pytest` and `pytest --pg`. Real database only with `OMARCHY_DB_LIVE=1` (the unit sets it).
